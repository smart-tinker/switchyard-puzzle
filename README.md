# Стрелочная

Браузерная головоломка. Переключайте стрелки и отправляйте составы на пути A, B или C за ограниченное число переводов. В очереди видны предстоящие составы: положение обеих стрелок сохраняется между отправками.

- Сенсорное управление или клавиши 1, 2 и пробел.
- Восемь смен, прогресс хранится в браузере. Без учётных записей, собственного сервера и покупок.
- CI собирает два ZIP: обычный switchyard.zip без сетевых SDK и switchyard-yandex.zip с подключением SDK по /sdk.js. Оба архива статические. Переносимый архив не является интеграцией с другой площадкой.
- GitHub Actions проверяет правила, формирует ZIP и запускает Chromium на распакованном архиве с имитацией SDK. Это не заменяет проверку черновика в кабинете Яндекс Игр.

Работа ведётся через issues и PR. Сборка для проверки должна ссылаться на точный SHA. Реквизиты, логины и данные кабинета в репозиторий не добавляются.

## Смена дня

Дополнительная очередь из восьми составов меняется каждый день по UTC. Старайтесь пройти её за меньшее число переводов стрелок. Лучший результат за день сохраняется в этом браузере. Регистрация, сервер и сетевой рейтинг не нужны.

Черновой релиз дополнительно содержит `switchyard-promo.zip`: иконка 1024×1024, обложка 1920×1080 и четыре скриншота 1280×720 из проверенной сборки. Промоматериалы не входят в игровой ZIP.
